# Text RPG

Текстовая RPG по загруженной книге: сюжет и бой ведёт LLM, прогрессия и правила считаются на сервере.

## Запуск

```powershell
cd C:\TextRPG
python start.py
```

`start.py` поднимает сервер на http://127.0.0.1:8001 и, дождавшись готовности,
сам открывает игру в новом окне браузера. Остановить сервер — `Ctrl+C`.

Полезные флаги:

```powershell
python start.py --port 8002     # другой порт
python start.py --no-browser    # сервер без автооткрытия браузера
```

Вручную (без автооткрытия):

```powershell
cd C:\TextRPG
python -m uvicorn main:app --port 8001 --host 127.0.0.1
```

Игра: http://127.0.0.1:8001

Двойной клик по `Start Server.cmd` делает то же самое (запускает `start.py` и
открывает игру в новом окне браузера).

## Настройки

Ключ ИИ можно задать двумя способами.

1. **В игре** — кнопка «☰ Меню» → «Ключ ИИ». Здесь выбирается бесплатный
   провайдер (Google Gemini, Groq, OpenRouter, Mistral), proxyapi или «Свой
   адрес» (любой OpenAI-совместимый сервер, например локальная Ollama). Ключ
   хранится только на устройстве, в `data/settings.json`, и наружу отдаётся
   только маской. Кнопка «Проверить» делает пробный запрос к модели.
2. **Через `.env`** (запасной вариант для proxyapi на ПК; файл в git не попадает):

```
PROXYAPI_KEY=ваш_ключ
```

Образец — `.env.example`. Настройки из меню имеют приоритет над `.env`.

Бесплатные ключи нельзя «вшить» в игру: они привязаны к аккаунтам, а лимиты
общие. Поэтому в каталоге есть ссылки «где взять ключ» — получить свой за
минуту.

## Меню игры

Кнопка «☰ Меню» открывает:

- **Ключ ИИ** — выбор провайдера, модели и ключа (см. выше);
- **Настройки звука** — общая громкость, эффекты, музыка (звуки пока не
  подключены, значения сохраняются заранее);
- **Обновления** — репозиторий GitHub вида `владелец/репозиторий`, авто-проверка
  при запуске и кнопка «Проверить сейчас» (см. «Обновления APK»);
- **Сохранить лог файл** — выгружает историю приключения и технический журнал
  одним `.txt` (браузер — скачиванием, Android — в «Загрузки»);
- **Выйти** — закрывает приложение (в браузере — вкладку).

## Жанры и опыт

- Жанр выбирается при загрузке книги (основной и необязательный второй тон).
- Профиль жанра задаёт тон повествования, акценты опыта, подписи характеристик и стартовый набор.
- Опыт начисляет сервер по тегу `[EVENT]`: тип, результат и сложность события. Числа от LLM не используются.
- Повторяющиеся действия дают всё меньше опыта, а бюджет сцены ограничивает фарм.
- Новая книга = новый герой и новая история: прогресс сбрасывается.

## Сессии и «Сменить книгу»

- Кнопка «Сменить книгу» сначала предупреждает, что начнётся новая игра.
- Текущая сессия сохраняется: снимок игрока пишется в таблицу `game_saves`.
- Затем создаётся новый пустой герой с тем же `user_token`, и игра начинается с первого шага (имя → жанр → книга).
- Полный снимок игрока: сервис `app/services/saves.py`; сохранения группируются по `user_token` (хранится в браузере).
- Список сохранений: `GET /saves?user_token=...`.

## Способности

- Каталог способностей зависит от жанра кампании (по 6 в наборе); механики общие для всех жанров.
- Эффекты: урон, лечение, щит, прилив сил, озарение, обаяние, скрытность.
- Способность видна сразу, но закрыта, пока не изучена. Изучение и повышение ранга стоят очки способностей (цена = тир).
- Ранги: до 3. Ранг усиливает эффект, перезарядка ограничивает частоту применения.
- Способности работают в бою и вне боя (`combat` / `field`), сервер сам считает эффект.
- Книжные способности выдаёт сюжет тегом `[ABILITY_UNLOCK]`; они появляются как открытые и помечены как книжные.
- Данные — `app/content/abilities.py`; логика — `app/services/abilities.py`; API — `GET /abilities/{id}`, `POST /abilities/{id}/learn`, `POST /abilities/{id}/use`, `POST /combat/{id}/ability`.

## Данные

- `data/rpg.db` — база игроков;
- `data/books/book_<id>.json` — книга, разбитая на фрагменты с эмбеддингами;

- `data/debug.log` — последние ответы LLM.

## Android (APK)

Игру можно собрать в APK: Python-сервер работает внутри приложения, интерфейс
показывается в WebView. Проект лежит в `android/`, инструкция по сборке —
`android/README.md`.

Особенность телефона: локальной Ollama там нет, поэтому поиск по книге идёт
по словам (BM25), а книгу можно загружать прямо на телефоне (предобработка
на ПК не требуется). На десктопе поиск остаётся гибридным (смысл + слова).

## Обновления APK (без USB-кабеля)

Приложение умеет обновлять само себя из **GitHub Releases**:

1. Создайте репозиторий на GitHub и запомните его адрес вида
   `владелец/репозиторий`.
2. Соберите APK (`android/README.md`) и приложите его к релизу с тегом версии,
   например `v1.2.0` (тег новее — версия считается новее; сравнение по числам).
3. В игре: «☰ Меню» → «Обновления», впишите `владелец/репозиторий`, включите
   «Проверять при запуске» и «Сохранить».

Дальше при запуске приложение само спросит GitHub о последнем релизе. Если там
есть `.apk` новее текущей версии, сверху появится баннер «Доступно обновление»;
по кнопке «Обновить» APK скачается и откроется системный установщик (одно
подтверждение — Android не позволяет ставить приложения полностью молча без
Google Play).

Версия игры задана в двух местах и должна совпадать: `APP_VERSION` в
`app/config.py` (ПК) и `versionName` в `android/app/build.gradle.kts`.
При выпуске новой версии поднимайте `versionCode` (целое число) и `versionName`.
