# Text RPG

Текстовая RPG по загруженной книге: сюжет и бой ведёт LLM, прогрессия и правила считаются на сервере.

## Запуск

```powershell
cd C:\TextRPG
python start.py
```

`start.py` поднимает сервер на http://127.0.0.1:8001 и, дождавшись готовности,
сам открывает игру в новом окне браузера. Остановить сервер — `Ctrl+C`.

Полезные флаги:

```powershell
python start.py --port 8002     # другой порт
python start.py --no-browser    # сервер без автооткрытия браузера
```

Вручную (без автооткрытия):

```powershell
cd C:\TextRPG
python -m uvicorn main:app --port 8001 --host 127.0.0.1
```

Игра: http://127.0.0.1:8001

Двойной клик по `Start Server.cmd` делает то же самое (запускает `start.py` и
открывает игру в новом окне браузера).

## Жанры и опыт

- Жанр выбирается при загрузке книги (основной и необязательный второй тон).
- Профиль жанра задаёт тон повествования, акценты опыта, подписи характеристик и стартовый набор.
- Опыт начисляет сервер по тегу `[EVENT]`: тип, результат и сложность события. Числа от LLM не используются.
- Повторяющиеся действия дают всё меньше опыта, а бюджет сцены ограничивает фарм.
- Новая книга = новый герой и новая история: прогресс сбрасывается.

## Сессии и «Сменить книгу»

- Кнопка «Сменить книгу» сначала предупреждает, что начнётся новая игра.
- Текущая сессия сохраняется: снимок игрока пишется в таблицу `game_saves`.
- Затем создаётся новый пустой герой с тем же `user_token`, и игра начинается с первого шага (имя → жанр → книга).
- Полный снимок игрока: сервис `app/services/saves.py`; сохранения группируются по `user_token` (хранится в браузере).
- Список сохранений: `GET /saves?user_token=...`.

## Способности

- Каталог способностей зависит от жанра кампании (по 6 в наборе); механики общие для всех жанров.
- Эффекты: урон, лечение, щит, прилив сил, озарение, обаяние, скрытность.
- Способность видна сразу, но закрыта, пока не изучена. Изучение и повышение ранга стоят очки способностей (цена = тир).
- Ранги: до 3. Ранг усиливает эффект, перезарядка ограничивает частоту применения.
- Способности работают в бою и вне боя (`combat` / `field`), сервер сам считает эффект.
- Книжные способности выдаёт сюжет тегом `[ABILITY_UNLOCK]`; они появляются как открытые и помечены как книжные.
- Данные — `app/content/abilities.py`; логика — `app/services/abilities.py`; API — `GET /abilities/{id}`, `POST /abilities/{id}/learn`, `POST /abilities/{id}/use`, `POST /combat/{id}/ability`.

## Данные

- `data/rpg.db` — база игроков;
- `data/books/book_<id>.json` — книга, разбитая на фрагменты с эмбеддингами;
- `data/source/` — исходные тексты;
- `data/debug.log` — последние ответы LLM.
