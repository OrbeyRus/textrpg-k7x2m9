# Text RPG для Android (Chaquopy)

Этот каталог — Android-проект, который упаковывает ту же игру в APK.
Никакого отдельного сервера не нужно: Python-сервер (`main:app`) запускается
**внутри приложения**, а интерфейс открывается в WebView на `http://127.0.0.1:8001`.

Код игры не дублируется: перед сборкой Gradle копирует `main.py`, `app/`,
`static/` и `index.html` из корня проекта в `app/src/main/python`.

---

## Как это работает

```
Kotlin (MainActivity) ──► Chaquopy запускает Python-сервер в фоне
        │                          │
        └──► WebView открывает ◄───┘  http://127.0.0.1:8001
```

- Сервер и логика — тот же код, что на десктопе.
- Данные (`rpg.db`, книги, логи) пишутся в приватную папку приложения
  (`/data/data/com.textrpg.app/files`), код там только для чтения.
- LLM вызывается по интернету (proxyapi) — телефону нужен доступ в сеть.

## ⚠️ Поиск по книге на телефоне работает по словам

На десктопе поиск по книге «умный» (эмбеддинги через локальную **Ollama**).
На телефоне Ollama нет, поэтому:

- **семантический поиск недоступен** — считать вектор *запроса игрока* нечем;
- поиск идёт по словам (алгоритм BM25): это надёжно и полностью офлайн;
- **книгу можно загружать прямо на телефоне** кнопкой загрузки — сервер сам
  разобьёт `.txt` на куски. Предварительная обработка на ПК не нужна.

Десктопная версия при этом не меняется: там, где Ollama доступна, поиск
по-прежнему гибридный (смысл + слова).

## Что понадобится

1. **Android Studio** (актуальная версия) — https://developer.android.com/studio
2. **Python 3.11** на компьютере сборки. Версия должна совпадать с
   `version = "3.11"` в `app/build.gradle.kts`. Проверить:
   ```powershell
   py -3.11 --version
   ```
   Если такой версии нет — установите Python 3.11, либо поменяйте версию
   в `build.gradle.kts` на ту, что у вас есть (например `3.12`).
3. Ключ `PROXYAPI_KEY` (тот же, что в `.env` на десктопе).

## Сборка

1. В Android Studio: **Open** → выберите папку `C:\TextRPG\android`.
2. Дайте проекту синхронизироваться: Studio скачает Gradle, плагин Chaquopy и
   Python-пакеты (это долго в первый раз; нужен интернет).
3. Запустите на телефоне (USB + отладка) или соберите APK:
   **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
   Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

Установка на телефон: скопируйте APK и откройте его, разрешив установку
из неизвестных источников.

### Если Gradle не находит Python

Chaquopy ищет на машине сборки Python той самой версии. Если `py -3.11` не
работает, укажите путь явно в `app/build.gradle.kts`:
```kotlin
chaquopy {
    defaultConfig {
        buildPython("C:/Путь/к/Python311/python.exe")
    }
}
```

## Первый запуск

1. Приложение спросит **PROXYAPI_KEY** — вставьте ключ и сохраните
   (он хранится в настройках приложения; изменить можно через меню «Ключ API»,
   после смены нужно перезапустить приложение).
2. Загрузите книгу `.txt` обычной кнопкой в интерфейсе — откроется системный
   выбор файла.

Данные приложения (для отладки) лежат в
`/data/data/com.textrpg.app/files` и видны в Android Studio через
**Device File Explorer** (для debug-сборки).

## Размер APK

Ориентировочно **35–60 МБ**: внутрь попадают интерпретатор Python (Chaquopy)
и две архитектуры (`arm64-v8a`, `x86_64`). Нативных pip-пакетов нет — numpy
не нужен, так как на телефоне поиск лексический, поэтому сборка не зависит от
наличия готовых Android-колёс. Если размер мешает, уберите `x86_64` из
`abiFilters` (он нужен только эмулятору) — но тогда на эмуляторе не запустится.

## Если что-то не так

- **Ошибки pip при синхронизации** («No matching distributions…») — значит
  пакет недоступен для Android. Сообщите текст ошибки: подберём версию.
- **`ModuleNotFoundError`** в логах — пакет не добавлен в блок `pip`.
- **Приложение «вылетает»** — смотрите Logcat. Вывод Python идёт в теги
  `python.stdout` и `python.stderr`.
- **Белый экран** — сервер не успел подняться или упал; проверьте Logcat.
- **Ошибка сети/ключа** — проверьте `PROXYAPI_KEY` и интернет.

---

## Изменение кода игры

Меняйте код в корне проекта (`app/`, `static/`, `index.html`) как обычно —
это единственный источник правды. При следующей сборке APK Gradle сам
скопирует свежие файлы в `app/src/main/python` (этот каталог создаётся
сборкой и в git не попадает).
